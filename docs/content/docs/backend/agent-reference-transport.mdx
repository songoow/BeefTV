---
title: Agent 生成的参考素材传输
description: 外部 Agent 与内置制作流程如何继承模型设置中的参考图片、视频和音频传输方式
---

通过 `canvas.generation.propose` / `canvas.generation.submit` 提交的生成任务，使用当前已启用渠道中已选模型的配置。参考素材的传输方式来自该模型的「配置使用 → 参考素材传输」，与画布手动生成使用同一项设置。

## 按模型、按素材类型设置

第三方模型的图片、视频和音频可以分别选择：

| 选项 | 行为 |
| --- | --- |
| 自动，按协议处理 | 使用当前协议插件的默认传输方式；不自动改为内嵌素材。 |
| 直接传素材 | 从当前工作区读取素材，按协议使用文件或 Base64。上游必须支持这种输入方式。 |
| 上传到我的对象存储 | 将本地素材上传到已启用的对象存储，再把可访问链接交给上游。 |
| 手动填写 HTTPS 链接 | 使用调用路径已经提供的在线链接，不自动上传本地素材。 |

此设置保存在 `channels[].modelProfiles[].referenceMediaTransport`，没有渠道级的同名默认项。系统渠道使用系统自己的传输策略。Agent 的节点参数不能覆盖这项模型设置，也不能通过选择其他模型的 profile 获得不同策略。

## 提交与验收

1. 在模型设置里保存适用的图片、视频、音频传输方式。
2. 读取 `model.catalog`，配置节点并用 `canvas.get` 核对；确认参考节点的素材已经保存。
3. 提出生成单并核对参数及报价，再按现有授权方式提交。修改模型设置后重新提出生成单，避免提交过期配置版本。
4. 提交时把所选模型的传输配置写入任务，执行时按该配置读取参考素材。

工作流在选择模型或重新保存同一模型时，也会读取当前模型 profile 的传输方式。已保存的工作流配方和已经提交的任务保留当时的传输设置；执行或重试时刷新渠道凭据不会改写该设置。需要改变工作流传输方式时，先修改模型设置，再重新保存工作流。

高层画布生成操作要求参考节点已保存为当前工作区的 `resource:` 素材。若模型要求在线链接，而这些素材仍在本地且没有可用对象存储，提交会因参考素材需要在线链接而拒绝入队；不会把「自动」「对象存储」或「手动链接」悄悄改成直接传素材。手动链接模式也不会把高层操作中的本地资源变成公网链接。

传输方式解决的是素材如何送到模型。它不改变模型支持的参考角色、数量、内容限制或画面质量；任务成功后仍需检查实际产物。
